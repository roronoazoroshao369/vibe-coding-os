# Skill Proposal Template

> Use this template when proposing a new skill for Vibe Coding OS.

## Metadata

- Skill name:
- Category: (core / agents / memory / meta / prompts)
- Proposed by:
- Date:
- Stack / domain:

## Problem Statement

Describe the problem this skill solves and who benefits from it.

## Proposed Skill Content

### Trigger Conditions

List the conditions that should activate this skill.

### Steps

Provide numbered, concrete steps for the workflow.

### Pitfalls

List known issues, anti-patterns, and failure modes.

### Verification

Describe how to verify the skill was applied correctly.

## Examples

Provide 1-2 concrete examples showing before/after or trigger/output.

## Files to Create

List expected file paths:

- `skills/<category>/<skill-name>/SKILL.md`
- Any supporting files under `references/`, `templates/`, `scripts/`, `assets/`

## Validation Checklist

- [ ] SKILL.md has valid YAML frontmatter
- [ ] Required sections present: description, trigger conditions, steps, pitfalls
- [ ] No broken internal references
- [ ] Bilingual note included if user-facing
- [ ] Fits existing category structure

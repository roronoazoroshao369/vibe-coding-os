# License Attribution Template (NOTICE)

## When to fill

Generated automatically by `vibe-license-surface` command. This template shows the expected format.

## Structure

```
This product includes software developed by third parties:

- <package-name> (<license>) — copyright <year> <author>
- <package-name> (<license>) — copyright <year> <author>
...
```

## License classes

- **permissive**: MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0, ISC
- **copyleft-weak**: LGPL-2.1, LGPL-3.0, MPL-2.0, EPL-2.0
- **copyleft-strong**: GPL-2.0, GPL-3.0, AGPL-3.0
- **proprietary**: requires explicit grant
- **unknown**: no license metadata found

## Output location

`docs/security/license-reports/<date>-<scope>.notice`

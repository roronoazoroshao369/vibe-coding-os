# Contributing Skills

See `docs/CONTRIBUTING-SKILLS.md` for the full guide on authoring skills.

## Quick start

1. Read the skill you want to mirror (e.g., `skills/core/disciplined-diagnosis/SKILL.md`).
2. Copy its structure: Purpose → When to use → Inputs → Workflow → Outputs → Failure modes → Verification checklist → Related skills.
3. Add YAML frontmatter with all required fields.
4. Run `npm run validate:skill-quality` to confirm.

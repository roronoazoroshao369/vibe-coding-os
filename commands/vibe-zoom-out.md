# Command: Zoom out on system context

## When to use

Use before architecture-sensitive or unfamiliar-code changes.

## Required inputs

Target files, proposed change, context docs.

## Step-by-step behavior

1. Inspect surrounding code/docs.
2. Explain boundaries and invariants.
3. Identify risks and options.
4. Recommend next workflow.

## Outputs

System context brief and recommendation.

## Stopping conditions

Stop before editing; this command is analysis-first.

## Verification checklist

Concrete files and assumptions are referenced.

## Ghi chú tiếng Việt

Lùi lại nhìn toàn hệ thống trước khi sửa chỗ rủi ro.

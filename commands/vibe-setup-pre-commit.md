# Command: Setup pre-commit quality gates

## When to use

Use when a repo needs lightweight local quality gates.

## Required inputs

Existing scripts, stack, hook policy.

## Step-by-step behavior

1. Inspect scripts/hooks.
2. Choose existing checks.
3. Document hook/CI relationship.
4. Validate if possible.

## Outputs

Quality-gate plan or hook docs.

## Stopping conditions

Stop before adding dependencies without approval.

## Verification checklist

Checks are useful, fast, and maintainable.

## Ghi chú tiếng Việt

Thiết lập kiểm tra trước commit nhẹ, không thêm dependency bừa.

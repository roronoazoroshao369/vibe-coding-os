# Command: Compressed technical communication

## When to use

Use when user requests terse expert communication.

## Required inputs

Topic, audience, must-keep facts.

## Step-by-step behavior

1. Drop filler.
2. Keep exact identifiers/commands.
3. Preserve uncertainty and risks.
4. Use dense bullets.

## Outputs

High-signal concise response.

## Stopping conditions

Stop if the audience needs teaching detail.

## Verification checklist

No critical caveat was compressed away.

## Ghi chú tiếng Việt

Nói ngắn, sắc, đủ kỹ thuật; không giấu rủi ro.

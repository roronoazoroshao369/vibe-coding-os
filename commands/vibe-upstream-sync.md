# vibe-upstream-sync

Synchronize and audit tracked upstream references without vendoring their source. Read `references/index.json`, run `npm run references:clone` when local clones are needed, inspect only the relevant upstream files, summarize reusable ideas in original language, update the matching source changelog and metadata, adapt only high-fit improvements into local Vibe Coding OS files, and run validation. Before committing, confirm `references/upstreams/` clone contents are ignored and not staged.

# Command: Triage task or issue

## When to use

Use for incoming bugs/features/questions or backlog cleanup.

## Required inputs

Issue text, labels, reproduction info, priority signals.

## Step-by-step behavior

1. Classify the work.
2. Identify missing evidence.
3. Recommend state/label/owner.
4. Provide next action.

## Outputs

Triage decision and next step.

## Stopping conditions

Stop before implementing; triage is classification and routing.

## Verification checklist

Decision has rationale and missing info is explicit.

## Ghi chú tiếng Việt

Phân loại issue có căn cứ, không nhảy vào sửa ngay.

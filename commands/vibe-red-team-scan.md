# Command: Vibe Red Team Scan

## When to use

Use this command to scan a third-party skill, a community contribution, or a marketplace item for known bypass techniques, prompt-injection payloads, and embedded secrets.

## Required inputs

- Target (file path or content)
- Scan depth
- Output mode

## Outputs

- Scan report
- Risk score and findings list
- Recommendation

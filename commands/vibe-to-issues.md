# Command: Slice work into issues

## When to use

Use after PRD/spec/plan approval for multi-slice work.

## Required inputs

Approved artifact, issue tracker conventions, validation commands.

## Step-by-step behavior

1. Identify vertical slices.
2. Add acceptance criteria and checks.
3. Name dependencies.
4. Produce independently grabbable issues.

## Outputs

Issue list or issue markdown.

## Stopping conditions

Stop if source artifact is not approved or scope is unclear.

## Verification checklist

Each issue is independently reviewable/testable.

## Ghi chú tiếng Việt

Chia việc thành issue nhỏ có thể giao cho agent/người khác.

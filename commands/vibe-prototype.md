# Command: Prototype before commitment

## When to use

Use when uncertainty is high and a disposable experiment can answer it.

## Required inputs

Question, timebox, boundaries, success criteria.

## Step-by-step behavior

1. Define uncertainty.
2. Build/design smallest experiment.
3. Capture findings.
4. Decide discard/adapt/proceed.

## Outputs

Prototype report and recommendation.

## Stopping conditions

Stop before merging throwaway code accidentally.

## Verification checklist

Prototype answered the stated question.

## Ghi chú tiếng Việt

Thử nghiệm nhanh để học, không âm thầm ship prototype.

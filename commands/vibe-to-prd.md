# Command: Create PRD from context

## When to use

Use when conversation contains enough product intent for a durable PRD.

## Required inputs

Conversation context, goals, constraints, non-goals.

## Step-by-step behavior

1. Extract stated requirements.
2. Fill PRD template.
3. Mark assumptions/open questions.
4. Request approval for meaningful scope.

## Outputs

PRD draft with acceptance criteria.

## Stopping conditions

Stop if key product facts are missing and ask questions.

## Verification checklist

No invented requirements; criteria are testable.

## Ghi chú tiếng Việt

Biến ngữ cảnh thành PRD gọn, không bịa.

# Command: Vibe Adversarial Review

## When to use

Use this command when you want an attacker-perspective review of a code change, a published skill, or a feature spec.

## Required inputs

- Target (file path, PR URL, or feature spec)
- Adversary model
- Trust boundary list

## Outputs

- Adversarial review report
- Risk score
- Recommended mitigations

# vibe-specify (DEPRECATED)

> ⚠️ **Deprecated.** This command has been unified into `commands/vibe-spec.md`.
>
> Both commands did the same thing (produce a spec from goals/acceptance-criteria).
> Use `vibe-spec` instead — it covers the same workflow with richer step-by-step
> guidance, template binding, and verification. `vibe-specify` remains here for
> backward compatibility but will be removed in the next major version.
>
> **Migration:** Replace any reference to `vibe-specify` with `vibe-spec`.
> The underlying template (`templates/spec-template.md`) is identical.

## Purpose (original)

Produce a behavior-focused specification (the "what") with goals, non-goals, user
scenarios, and observable acceptance criteria, deferring technical choices to planning.

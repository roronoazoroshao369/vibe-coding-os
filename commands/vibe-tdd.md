# Command: Use TDD loop

## When to use

Use for behavior changes or regressions.

## Required inputs

Acceptance criteria, test framework, target slice.

## Step-by-step behavior

1. Pick one slice.
2. Write failing test.
3. Confirm red.
4. Implement minimal code.
5. Confirm green.
6. Refactor safely.

## Outputs

Red/green evidence and implemented slice.

## Stopping conditions

Stop if no test path exists and document alternate verification.

## Verification checklist

Red and green states recorded.

## Ghi chú tiếng Việt

Làm theo red-green-refactor cho từng lát nhỏ.

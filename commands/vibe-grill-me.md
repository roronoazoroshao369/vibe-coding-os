# Command: Grill user before building

## When to use

Use for ambiguous or high-impact requests before implementation.

## Required inputs

User request, constraints, known context.

## Step-by-step behavior

1. Restate the goal.
2. Ask focused questions about outcomes, edge cases, non-goals, risks, and acceptance criteria.
3. Summarize decisions and open assumptions.

## Outputs

Alignment summary and next recommended artifact.

## Stopping conditions

Stop when enough is known for a spec/PRD/plan, or when user asks to proceed with explicit assumptions.

## Verification checklist

No hidden assumptions; acceptance criteria are testable.

## Ghi chú tiếng Việt

Hỏi kỹ trước khi làm để tránh agent tự đoán requirement.

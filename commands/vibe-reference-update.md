# vibe-reference-update

Update Vibe Coding OS based on audited upstream changes. Perform impact analysis from `references/index.json` and mappings, edit only local files that clearly benefit, keep all content original, document decisions in changelogs or mappings, avoid unnecessary churn, preserve attribution hygiene, and run `npm run validate:references` plus `npm run validate` when applicable.

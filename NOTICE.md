# Notices

Vibe Coding OS is an original framework for AI-assisted software workflows.

This v0.1 kernel includes attribution placeholders and a source registry but does not vendor external code, prompts, documentation, datasets, or skill files from other repositories.

If future versions import or adapt external material, contributors must:

- verify the upstream license before import;
- add or update entries in `registry/sources.json`;
- document the imported material in `ATTRIBUTIONS.md`;
- include any required upstream notices;
- keep copied text minimal and clearly identified.

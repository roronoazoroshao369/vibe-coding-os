# Feature: Project Standards and Roadmap

## Purpose

Keep durable project principles, current working conventions, and product direction separate so agents can plan accurately without bloating every spec.

## Local files

- `CONSTITUTION.md` — highest-priority principles.
- `STANDARDS.md` — current coding, docs, validation, attribution, and command-handoff conventions.
- `ROADMAP.md` — mission, roadmap themes, and product-direction notes.
- `CONTEXT.md` — shared vocabulary.

## Policy

Specs describe behavior. Plans cite standards and roadmap only when they constrain implementation or priority. User intent still wins over roadmap preferences when explicit and safe.

## Ghi chú tiếng Việt

Tách principle (`CONSTITUTION.md`), convention (`STANDARDS.md`), direction (`ROADMAP.md`), và vocabulary (`CONTEXT.md`) để agent không trộn chiến lược vào spec hành vi.

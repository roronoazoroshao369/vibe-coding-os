# Feature: Compressed Technical Communication

## Goal

Use terse expert communication without losing correctness or caveats.

## Reference sources

Upstream caveman concept; local prompt style.

## Local implementation

Implemented by `skills/prompts/compressed-technical-communication/SKILL.md` and `commands/vibe-caveman.md`.

## Must-have behavior

Compress filler, preserve identifiers and uncertainty, expand when stakes or audience require.

## Failure modes

Cryptic output, missing caveats, rude tone.

## Update signals

Upstream changes caveman style or constraints.

## Evaluation ideas

Compare compressed and normal summaries for factual equivalence.

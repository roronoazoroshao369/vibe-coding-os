# Feature: Architecture Improvement

## Goal

Zoom out, prototype, and improve architecture with small verified changes.

## Reference sources

Upstream improve-codebase-architecture, zoom-out, and prototype concepts.

## Local implementation

Implemented by `skills/core/improve-codebase-architecture/SKILL.md`, `skills/core/zoom-out-system-context/SKILL.md`, `skills/core/prototype-before-commitment/SKILL.md`, related commands, templates, and workflow docs.

## Must-have behavior

Read context/ADRs, identify seams, protect behavior with tests, avoid big-bang rewrites.

## Failure modes

Aesthetic refactors, unverified rewrites, prototype code shipped by accident.

## Update signals

Upstream changes architecture deepening or prototype modes.

## Evaluation ideas

Run an architecture review and check whether it yields small slices plus ADR candidates.

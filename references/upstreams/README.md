# Upstream Working Copies

This directory is for local, disposable clones used during reference audits.

- Clone upstream repositories here only for inspection.
- Do not commit cloned upstream source trees.
- Record reusable findings in `references/changelogs/`, `references/sources/`, `references/mappings/`, and local Vibe Coding OS skills/templates/commands.
- Keep attribution decisions in `ATTRIBUTIONS.md` and `NOTICE.md` when material is imported or closely adapted.

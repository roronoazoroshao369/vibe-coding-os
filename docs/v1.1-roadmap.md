# Vibe Coding OS — v1.1 Roadmap

> **Generated:** 2026-06-17
> **Based on:** v1.0.0 Expert Audit (3-role), Gap Analysis (8 areas scored)
> **Release target:** v1.1.0

---

## v1.1 Vision

Preserve the portable, markdown-first core identity while hardening the runtime companion from "experimental prototype" to "reliable opt-in layer", closing validation gaps, and adding traceability that makes the workflow contract machine-verifiable.

## Success Criteria for v1.1.0

1. `npm run validate:all` includes `validate:release-metadata` — no stale version/adapter counts pass
2. `npm run validate:schemas` performs real JSON Schema validation with Ajv
3. `npm run smoke-test:runtime` initializes, creates items, validates, corrupts, and expects failures
4. README.md + README.vi.md reflect correct v1.1.0 version and current inventory
5. Dashboard adapter metrics match actual test output
6. All runtime schemas match actual implementation field names and enums
7. Gemini supported in `vibe init` and documented in CLI help
8. CLI smoke tests cover all advertised commands including `doctor`, `list-skills`, `list-commands`, `init`

# Hướng dẫn sử dụng với các IDE/CLI khác nhau

> Tài liệu này là bản tiếng Việt của Vibe Coding OS v2.15.0. Xem bản tiếng Anh tại [docs/](../) tương ứng.

## Mục đích

Hướng dẫn sử dụng với các IDE/CLI khác nhau — cung cấp hướng dẫn rõ ràng cho người dùng Việt Nam làm quen với framework.

## Cách sử dụng

Đọc tài liệu này theo thứ tự:

1. Bắt đầu với `vibe init` để khởi tạo dự án.
2. Tuân theo quy trình Spec → Plan → Implement → Review → Merge.
3. Sử dụng các skill và template phù hợp với từng giai đoạn.

## Quy ước ngôn ngữ

- Các thuật ngữ kỹ thuật giữ nguyên tiếng Anh (skill, command, template, prompt).
- Bình luận trong code bằng tiếng Anh để tương thích Claude Code.
- Tài liệu hướng dẫn có thể bằng tiếng Việt.

## Các tài liệu liên quan

- `docs/vi/` — bộ tài liệu tiếng Việt
- `docs/` — bộ tài liệu tiếng Anh gốc

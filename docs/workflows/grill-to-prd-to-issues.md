# Workflow: Grill to PRD to Issues

## Purpose

Grill to PRD to Issues.

## When to use

Use when a vague product request needs to become implementation-ready work.

## Step-by-step workflow

1. Grill for intent and non-goals.
2. Update context terms if durable.
3. Draft PRD from confirmed context.
4. Get approval or record assumptions.
5. Slice into independently grabbable issues.

## Required inputs

Initial request, business goal, constraints, acceptance criteria.

## Outputs

Alignment summary, PRD, issue slices, open questions.

## Related skills

grill-user-before-building, grill-with-docs, prd-from-context, issue-slicing.

## Related commands

`vibe-grill-me`, `vibe-grill-with-docs`, `vibe-to-prd`, `vibe-to-issues`.

## Maintenance notes

If upstream changes grilling/PRD/issues, update this workflow and templates together.

## Ghi chú tiếng Việt

Dùng khi ý tưởng còn mơ hồ. Kết quả phải là PRD/issue rõ, không bịa requirement.

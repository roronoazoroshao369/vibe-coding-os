# Workflow: Real Engineering Skills Workflow

## Purpose

Real Engineering Skills Workflow.

## When to use

Use for substantial software work that needs discipline without a heavyweight process.

## Step-by-step workflow

1. Setup project agent skills.
2. Grill the user before building.
3. Build or update shared domain language.
4. Capture important decisions as ADRs.
5. Convert context into PRD when needed.
6. Slice PRD/plan into issues.
7. Execute small vertical slices.
8. Use TDD for behavior changes.
9. Use diagnosis loop for bugs.
10. Zoom out before architecture-sensitive changes.
11. Improve architecture deliberately.
12. Handoff context when switching agents.
13. Verify with quality gates.

## Required inputs

User request, repo context, validation commands, relevant docs/ADRs.

## Outputs

Alignment summary, context/ADR updates, PRD/issues, implementation slices, handoff, validation evidence.

## Related skills

All mattpocock-inspired local skills plus existing spec/plan/review/verification skills.

## Related commands

`vibe-setup-skills`, `vibe-grill-me`, `vibe-grill-with-docs`, `vibe-to-prd`, `vibe-to-issues`, `vibe-tdd`, `vibe-diagnose`, `vibe-handoff`.

## Maintenance notes

Maintain by auditing `references/sources/mattpocock-skills.md`, mappings, and changelog when upstream changes.

## Ghi chú tiếng Việt

Workflow chính học tinh thần engineering thật: hỏi rõ, ghi context/ADR, PRD, chia issue, TDD/debug, handoff, validate. File ảnh hưởng: skills, commands, templates, references mappings.

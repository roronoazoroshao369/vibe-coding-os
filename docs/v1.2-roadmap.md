> **Generated:** 2026-06-17

---

## v1.2 Vision

v1.2 moves Vibe Coding OS from "hardened workflow framework" to "execution-ready discipline layer with enforceable multi-agent contracts."

Two themes:

1. **Contract rigor v2:** Runtime schemas evolve from permissive JSON shapes to enforceable multi-agent protocols with strict schemas, traceable actions, safety policies, and migration support.

2. **Adoption & evidence:** Reduce friction for real projects with polish commands, skill-pack installer, comparison docs, and benchmark-style evaluation.

## Success Criteria for v1.2.0

1. Dashboard is auto-generated from actual test output and matches 100%: gate count, adapter smoke, runtime smoke, version progress, orphan counts.
2. All runtime schemas use `additionalProperties: false` with explicit `metadata/extensions` escape hatch.
3. Task/team/workflow-run/checkpoint/session/memory schemas support multi-agent fields: claim, role permissions, gates, evidence, approval, provenance.
4. Action/event schemas provide full provenance linking actions to tasks/sessions/workflows/checkpoints.
5. Migration script upgrades v1→v2 state with backup, dry-run, idempotency, rollback.
6. Safety contract is enforced in MCP/tmux/daemon handlers.
7. `vibe install-pack` successfully installs at least core-solo and memory-safe packs.
8. Comparison docs for CrewAI, LangGraph, OpenHands exist and are honest about what Vibe is not.
9. Security model doc exists and covers all known threat boundaries.
10. `npm run validate:all`, `smoke-test:cli`, `smoke-test:adapters`, `smoke-test:runtime` all pass at 100%.

## Effort Estimation Notes

- v1.1 effort proved that P0/P1 items averaging 3–12h each are realistic.
- v1.2 P1 items are larger (6–12h each) because they touch schemas + stores + CLIs.
- Migration (P1.5, 12h) is high-risk: backup + dry-run + idempotency + rollback all needed before runtime upgrade is safe.
- 150h total is about 3–4 weeks for a focused developer, or 6–8 weeks for part-time work.

## Out of Scope for v1.2

The following are deliberately deferred to avoid scope creep:

- Full autonomous agent runtime (OpenHands-scale)
- Cloud/hosted service
- LangGraph-like graph DSL engine
- Browser/editor-integrated coding environment
- npm package with auto-installer
- Workshop/hackathon materials
- AI-produced video tutorials

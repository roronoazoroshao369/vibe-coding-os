## Background

Quality Telemetry captures structured events from each quality engine run. The trend report aggregates those events into a single Markdown document covering:

- **Pass/fail rates over time** — day-by-day movement in gate pass rate, event result mix, and total sessions
- **Duration averages** — average wall-clock time per event, bucketed by day, gate, and model
- **Gate-level breakdown** — per-gate pass rate, failure count, and average duration, sorted by failure density
- **Model-level comparison** — pass rate and duration by model or profile, including lowest/highest performers
- **Task-type breakdown** — pass rate and duration by task category (api-change, refactor, bugfix, etc.)
- **Insights and recommended follow-up** — automated delta calculations, regression spotting, and concrete improvement suggestions

4. **Pass rate ranges from 51% to 76% across the 7 days** with noticeable dips on 2026-06-15 and 2026-06-17. Volume correlates inversely with quality — heavy days tend to have lower pass rates, which may point to resource contention or user fatigue during high-activity periods.

## Usage

To generate your own trend report:

```bash
# Full report to file
node scripts/quality-telemetry-report.mjs --since 7d

# JSON for programmatic use
node scripts/quality-telemetry-report.mjs --since 30d --json

# Filter by model and print to stdout
node scripts/quality-telemetry-report.mjs --model gpt-4o-mini --since 14d --stdout

# Filter by task type
node scripts/quality-telemetry-report.mjs --task-type refactor --since 30d --stdout
```

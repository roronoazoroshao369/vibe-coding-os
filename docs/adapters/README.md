# Adapter Hub

This directory contains tool-specific setup guides for Vibe Coding OS. Each adapter explains how to initialize the framework for a particular AI coding assistant.

## Supported Adapters

| Tool | Adapter Doc | `vibe init` command |
|------|-------------|---------------------|
| Claude Code | [claude-code.md](claude-code.md) | `vibe init claude-code` |
| Codex CLI | [codex.md](codex.md) | `vibe init codex` |
| Cursor | [cursor.md](cursor.md) | `vibe init cursor` |
| Gemini | [gemini.md](gemini.md) | `vibe init gemini` |

## How to use

1. **Pick your adapter** from the table above.
2. **Run the setup command** listed in the adapter doc.
3. **Follow the first workflow** to verify everything works.

> **Tip:** If you are new to Vibe Coding OS, start with the [First Workflow](../FIRST-WORKFLOW.md) guide instead of diving straight into adapter-specific details.

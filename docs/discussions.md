# GitHub Discussions Guide

This repository uses GitHub Discussions for community Q&A, show-and-tell, and feature brainstorming.

## Categories

We recommend setting up these discussion categories in your repo Settings → Discussions:

### 📣 Announcements
Project news, release announcements. **Maintainers only.**

### 🙋 Q&A
Get help using Vibe Coding OS. Use the Q&A template. Search before posting.

### 💡 Ideas
Suggest new skills, commands, templates, or workflow improvements. Use the Feature Request template.

### 🎉 Show and tell
Share what you built with Vibe. Use the Show and Tell template.

### 🛠️ Help wanted
Maintainer posts about skills/commands/templates that need contributions.

### 📚 General
Anything that doesn't fit the other categories.

## Setup checklist

To enable Discussions on your fork or related project:

1. Go to Settings → General → Features → Discussions
2. Check "Enable Discussions"
3. Create the 6 categories above
4. Add the 3 templates from `.github/discussion-templates/` to your repo

## Moderation

- Q&A threads older than 90 days without a marked answer are auto-archived
- Show and tell is moderated lightly — share freely
- Ideas require a maintainer to convert into issues before implementation

# v2.2.0 Release Notes — Quality Telemetry & Analytics

> **Release date:** 2026-06-19
> **Branch:** `feat/v2.2.0-quality-telemetry`
> **Status:** Release-ready; tag and GitHub release not created yet
> **Validation target:** 26/26 gates PASS

## Summary

v2.2.0 introduces quality telemetry collection and analytics for the Vibe Coding OS. It adds the ability to emit quality events from engine runs, aggregate session-level metrics, and generate local trend reports for continuous improvement. This release makes quality observable without requiring a hosted backend or external service.

This release remains additive. It does not require a daemon or hosted service, and respects ADR 0002 runtime-freeze boundaries.

## What's new

### Quality Telemetry skill

`skills/core/quality-telemetry/SKILL.md` documents how to collect local quality telemetry from engine runs, aggregate session metrics, and generate trend reports for continuous improvement.

### `vibe-quality-telemetry` command

`commands/vibe-quality-telemetry.md` provides a command prompt interface for emitting quality events, aggregating session metrics, and generating local trend reports.

### Quality Telemetry canonical guide

`docs/quality-telemetry-guide.md` explains all aspects: telemetry event schema, emit workflow, session metrics aggregation, trend report generation, and privacy/opt-in patterns.

### Package scripts

Three new npm scripts are available:

- `npm run quality:emit-event` — emit a quality event to the telemetry store
- `npm run quality:session-metrics` — aggregate session-level quality metrics
- `npm run quality:trend-report` — generate a local quality trend report

### Runtime script implementations

- `scripts/quality-event-emitter.mjs` — emit, query, and purge quality events
- `scripts/session-metrics-collector.mjs` — aggregate session-level quality metrics
- `scripts/validate-property-tests.mjs (replaced quality-trend v2.17)` — generate structured local trend reports

## Migration guide

No migration is required. Existing workflows continue to work.

Suggested adoption path:

1. Review `docs/quality-telemetry-guide.md` for an overview of telemetry collection and privacy.
2. Run `node scripts/quality-event-emitter.mjs --emit --model gpt-4o-mini --task-type api-change` to emit a sample quality event.
3. Run `node scripts/session-metrics-collector.mjs` to aggregate session-level metrics.
4. Run `node scripts/validate-property-tests.mjs (replaced quality-trend v2.17)` to generate a local trend report.
5. Use `vibe-quality-telemetry` command to integrate telemetry into workflow.
6. Run `npm run validate:all` to confirm 26/26 gates pass.

# v2.5.0 Release Notes — Advanced Orchestration

**Release date:** 2026-06-19
**Branch:** `feat/v2.5.0-advanced-orchestration`

## Summary

v2.5.0 Advanced Orchestration introduces stage-gated multi-agent workflows, an orchestration schema and runner, and workflow templates for features, bugfixes, and security audits. This completes the v1.7 → v2.5 roadmap.

## What's New

### Advanced Orchestration

- **Orchestration workflow schema** (`schemas/orchestration-workflow.json`) — defines the contract for multi-stage development workflows with stage IDs, roles, inputs, outputs, timeouts, retry policies, and gate references.
- **Workflow runner** (`scripts/orchestrate-workflow.mjs`) — executes orchestration workflows sequentially, enforcing gates at each stage. Supports `--workflow`, `--dry-run`, and `--output-json` flags.
- **Orchestration skill** (`skills/core/orchestration-workflows/SKILL.md`) — documents the full orchestration workflow: selecting templates, customizing stages, assigning agents, executing stages, enforcing gates, and generating reports.
- **`vibe-orchestrate` command** (`commands/vibe-orchestrate.md`) — CLI interface for running stage-gated orchestration workflows with plan, implement, review, verify, and handoff stages.

### Workflow Templates

Three workflow templates for common development scenarios:

- `templates/workflow-simple-feature.json` — standard feature pipeline: plan → implement → review → verify → handoff
- `templates/workflow-bugfix.json` — bugfix pipeline with root-cause analysis stage
- `templates/workflow-security-audit.json` — security-sensitive pipeline with enhanced gate requirements

### Orchestration Guide

`docs/orchestration-guide.md` — canonical guide covering usage, quick-start examples, failure modes, and integration with existing Vibe Coding OS quality tooling.

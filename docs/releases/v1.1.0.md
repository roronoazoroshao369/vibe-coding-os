# Vibe Coding OS v1.1.0 Release Notes

**Date:** 2026-06-17
**Status:** Final release — P0/P1/P2 hardening and expansion release.
**Primary change PR:** [PR #37](https://github.com/roronoazoroshao369/vibe-coding-os/pull/37)

---

## What's New

Vibe Coding OS v1.1.0 builds on the stable v1.0 Trusted Workflow Framework with a focused hardening pass across schema alignment, workflow state, runtime validation, CLI coverage, adapter packs, safety contracts, execution traceability, bilingual documentation sync, and markdown link validation.

Highlights:

- **Schema alignment:** registry, runtime, adapter, and validation contracts are now more consistent across the repository.
- **Workflow state hardening:** task, memory, checkpoint, team, session, daemon, MCP, and tmux runner flows are more explicit and inspectable.
- **Runtime validation:** local runtime checks, installer behavior, and smoke coverage are stronger.
- **CLI expansion:** command coverage is broader, with 20 CLI smoke tests passing.
- **Adapter packs:** Cursor, Codex, and Claude usage surfaces were refreshed for portable, tool-aware adoption.
- **Safety contracts:** hook expectations, secret scanning, injection scanning, memory redaction, and handoff behavior are clearer.
- **Execution trace:** local runtime activity can be logged and inspected through trace support.
- **Bilingual sync:** English/Vietnamese onboarding surfaces now have explicit sync validation.
- **Markdown links:** documentation links are validated before release to catch broken references.

## Breaking Changes

None.

## Migration

None required.

Users upgrading from v1.0.0 can continue using the markdown-first core workflow and optional runtime surfaces as before. Recommended post-upgrade verification:

```bash
npm run dashboard:generate
npm run validate:all
```

# v1.8.0 Release Notes — Expert Mode

> **Release date:** 2026-06-18
> **Branch:** `feat/v1.8.0-expert-mode`
> **Status:** Complete

## Summary

v1.8.0 Expert Mode extends the v1.7.0 Quality Shield with stronger review protocols, task-specific quality checklists, and multi-agent review patterns. It raises the quality ceiling for risky, ambiguous, or easy-to-rubber-stamp work without expanding the runtime scope.

## What's new

### Adversarial Code Review

A red-team code review skill that actively looks for ways a patch can be wrong, unsafe, insufficiently tested, incompatible, or larger than necessary.

- Skill: `skills/core/adversarial-code-review/SKILL.md`
- Command: `commands/vibe-red-team-review.md`

### Critique Pass Protocol

A structured writer-then-critic protocol that separates creation from criticism so assumptions, gaps, and weak verification are found before delivery.

- Skill: `skills/core/critique-pass-protocol/SKILL.md`
- Related prompt skill: `skills/prompts/critique-pass/SKILL.md`
- Command: `commands/vibe-critique-pass.md`
- Template: `templates/critique-pass-template.md`

### Task-specific quality packs

Five domain-focused checklists for recurring risky task types:

- **API endpoint quality** — `skills/checklists/api-endpoint-quality/SKILL.md`, `commands/vibe-quality-api.md`
- **Database migration quality** — `skills/checklists/db-migration-quality/SKILL.md`, `commands/vibe-quality-db-migration.md`
- **Auth and permissions quality** — `skills/checklists/auth-quality/SKILL.md`, `commands/vibe-quality-auth.md`
- **Frontend state quality** — `skills/checklists/frontend-state-quality/SKILL.md`, `commands/vibe-quality-frontend-state.md`
- **Async job quality** — `skills/checklists/async-job-quality/SKILL.md`, `commands/vibe-quality-async-job.md`

### Writer-Critic Pair

A two-role agent pattern for complex or high-stakes implementations where a writer creates and a critic independently challenges before delivery.

- Skill: `skills/agents/writer-critic-pair/SKILL.md`

### Canonical Expert Mode guide

`docs/expert-mode.md` explains all Expert Mode components, when to escalate from Quality Shield, and how to run an Expert Mode workflow.

### Quality Shield escalation

`docs/quality-shield.md` now links to `docs/expert-mode.md` and includes an "Escalating to Expert Mode" section.

### Registry synced

- `registry/skills.json` — `critique-pass-protocol` added (already-present adversarial-code-review, writer-critic-pair, and 5 quality-pack skills confirmed)
- `registry/prompts.json` — all v1.8 commands confirmed present

## Runtime scope

v1.8.0 respects ADR 0002. There is no runtime expansion, no new validation gate, and no dependency on Quality Engine runners or remote services.

## Known limitations

- Adversarial review and critique passes are currently manual; future versions may add automated runner support.

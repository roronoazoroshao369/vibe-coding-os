# v2.3.0 Release Notes — Multi-Repository Learning

> **Release date:** 2026-06-19
> **Branch:** `feat/v2.3.0-multi-repo-learning`
> **Status:** Release-ready; tag and GitHub release not created yet
> **Validation target:** 26/26 gates PASS

## Summary

v2.3.0 introduces Multi-Repository Learning — portable lesson exchange so repositories can share audited lessons without copying private project context or requiring a hosted service. This release makes cross-repo lesson transfer safe and explicit.

This release remains additive. It does not require a daemon or hosted service, and respects ADR 0002 runtime-freeze boundaries.

## What's new

### Multi-Repository Learning skill

`skills/core/multi-repo-learning/SKILL.md` documents how to export, review, and import portable coding lessons across repositories using the lesson exchange format.

### `vibe-lesson-exchange` command

`commands/vibe-lesson-exchange.md` provides a command prompt interface for exporting, checking, and importing lesson exchange batches.

### Multi-Repository Learning canonical guide

`docs/multi-repo-learning.md` explains the full workflow: quality check, export, review for safety, dry-run import, and final import.

### Lesson exchange schema

`schemas/lesson-exchange-format.json` defines the portable format for single lessons and exchange batches with fields for version, lessonId, repoId, modelId, timestamp, lessonType, pattern, context, fix, tags, confidence, scope, source, expiry, and crossRepoVerified.

### Sample template

`templates/lesson-exchange-sample.json` provides example lessons for the exchange format.

### Package scripts

Three new npm scripts are available:

- `npm run lesson:export` — export local lessons to a portable exchange batch
- `npm run lesson:import` — import a reviewed batch into the local lesson DB
- `npm run lesson:check` — validate local lesson quality before sharing

Plus a targeted validation script:

- `npm run validate:lesson-exchange` — run lesson quality checks

## Migration guide

No migration is required. Existing workflows continue to work.

Suggested adoption path:

1. Review `docs/multi-repo-learning.md` for an overview of the lesson exchange workflow.
2. Run `npm run lesson:check` to audit your local lesson DB quality.
3. Run `npm run lesson:export -- --scope framework` to export framework-scope lessons.
4. Review the exported batch for safety and portability.
5. In the target repo, run `node scripts/lesson-importer.mjs <batch.json> --dry-run` first.
6. Run `npm run lesson:import -- <batch.json>` after review.
7. Run `npm run validate:all` to confirm 26/26 gates pass.

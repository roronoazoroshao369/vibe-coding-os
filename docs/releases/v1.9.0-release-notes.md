> **Release date:** 2026-06-19

> **Validation target:** 25/25 gates PASS

## Summary

v1.9.0 Smart Adapt completes the Quality Elevation arc by making quality discipline adaptive to model weaknesses, task type, and lessons learned from prior work. It adds markdown-first skills, commands, and templates for remembering failure patterns, selecting stronger prompt stacks, and capturing reusable prevention rules.

This release remains additive. It does not introduce a new validation gate, does not expand the optional runtime, and preserves ADR 0002 runtime-freeze boundaries.

## What's new

### Smart Adapt canonical guide

The full Smart Adapt guide is at `docs/smart-adapt.md`, documenting how model weakness memory, adaptive prompt selection, lessons-learned DB, and golden examples work together.

### Model Weakness Memory

Track known failure modes for model types and inject targeted checks before similar tasks.

- Skill: `skills/core/model-weakness-memory/SKILL.md`
- Command: `commands/vibe-model-weakness.md`
- Template: `templates/model-weakness-log.md`

### Adaptive Prompt Selection

Classify task type, risk, and needed evidence level, then select the right quality prompt stack from the registry.

- Skill: `skills/core/adaptive-prompt-selection/SKILL.md`
- Command: `commands/vibe-adaptive-prompt.md`
- Template: `templates/adaptive-prompt-matrix.md`

### Lessons Learned DB

Capture repeated mistakes, fixes, root causes, and prevention prompts in a structured, searchable lesson format.

- Skill: `skills/core/lessons-learned-db/SKILL.md`
- Command: `commands/vibe-lessons-learned.md`
- Template: `templates/lesson-entry-template.md`

### Quality Scorecard Session

Adds a session-level scorecard template for quality tracking and release/readiness evidence.

- Template: `templates/quality-scorecard-session.md`

### Quality elevation examples

- Example hub: `examples/quality-elevation/README.md`
- Scenario files are present under `examples/quality-elevation/`.

## Migration guide

No migration is required. Existing workflows continue to work.

Suggested adoption path:

1. Run `vibe-adaptive-prompt` before non-trivial or risky work to choose the right quality stack.
2. Use `vibe-model-weakness` when a model has known failure patterns for the current task.
3. Capture repeated mistakes with `vibe-lessons-learned` and reuse prevention prompts in future work.
4. Record session quality outcomes with `templates/quality-scorecard-session.md`.

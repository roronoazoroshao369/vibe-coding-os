# v1.4.3 — Operational Hygiene

Release date: 2026-06-17

## Summary

v1.4.3 tightens runtime shell safety, completes the docs hub, and resolves all orphan templates. This is the last sprint before runtime freeze at v1.5.0.

## What changed

### Runtime — shell safety & state machine

- `claimTask()` now **rejects terminal states** (completed/cancelled) instead of silently claiming them.
- `renewTaskLease()` now caps the **absolute** expiry at `now + maxTaskLease`, preventing lease drift from migrated or corrupt data.
- `requireTmux()` now **throws an Error** instead of calling `process.exit(1)` — safe for library and test use.
- `mapResults()` returns final task objects after status updates instead of stale pre-update references.
- MCP `task.update` handler now forwards `actor: 'mcp'` into `updateTaskStatus()` for correct audit history.

### Runtime — config hardening

- Config validation now rejects zero, negative, or non-finite `maxTaskLease` values, silently resetting to default with a `_configWarning` field.

### Docs — identity & navigation

- **README diet:** reduced from 618 → ~260 lines. Product identity front and center.
- **`docs/README.md`** rewritten as a full docs navigation hub with categorized template links.
- **12 orphan templates resolved** — all templates now referenced from narrative docs. 0 orphans.
- **Doc role clarity:** INSTALL / QUICKSTART / FIRST-WORKFLOW now have explicit scope boundaries.
- **Vietnamese strategy doc:** updated to v1.4.2/v1.4.3.

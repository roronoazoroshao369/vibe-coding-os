# v2.8.0 Release Notes — Adapter Expansion

**Release date:** 2026-06-19
**Branch:** `main`

## Summary

v2.8.0 expands the adapter ecosystem to support 8 total AI coding assistants. Adds Cline, Continue.dev, Aider, and Windsurf adapters alongside existing Cursor, Aider, Claude Code, and Codex support.

## What's New

### New Adapters

- **Cline adapter** (`adapters/cline/`) — VS Code extension adapter for Cline AI assistant
- **Continue.dev adapter** (`adapters/continue/`) — Open-source AI code completion adapter
- **Windsurf adapter** (`adapters/windsurf/`) — Codeium's AI-native IDE adapter
- **Aider adapter** (`adapters/aider/`) — Terminal-based AI pair programming adapter

### Adapter Ecosystem

- **8 total adapters** — Cursor, Claude Code, Codex, Aider, Cline, Continue.dev, Windsurf, plus legacy support
- **Consistent adapter structure** — All adapters follow standardized README, configuration, and integration patterns
- **CLI smoke tests expanded** — Additional test coverage for new adapters

### Documentation

- **README Vietnamese sections** — Expanded bilingual documentation for Vietnamese community
- **Adapter comparison guide** — Updated to include all 8 supported adapters

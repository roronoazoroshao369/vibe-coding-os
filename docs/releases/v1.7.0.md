# v1.7.0 — Quality Shield

Release date: 2026-06-18

## Summary

v1.7.0 turns the Quality Shield from scattered quality artifacts into a discoverable, copy-pasteable workflow for real AI-assisted coding sessions.

This release keeps the runtime frozen. Quality Shield is a portable markdown-first discipline layer; Quality Engine remains the advanced/future orchestration layer.

## Highlights

- Adds the canonical guide: `docs/quality-shield.md`.
- Adds the copy-paste workflow: `docs/quality-shield-workflow.md`.
- Adds a concrete example: `examples/quality-shield/README.md`.
- Syncs discovery across README, docs hub, commands/skills/templates/registry READMEs, adapter docs, and examples.
- Reconciles v1.7 roadmap maturity with existing Quality Shield artifacts.
- Clarifies Quality Shield vs Quality Engine boundary.
- Keeps ADR 0002 runtime freeze intact.

## Quality Shield workflow

The release packages the workflow as five repeatable steps:

1. Quality Execution Contract
2. Code Context Pack
3. Implement the smallest safe diff
4. Self-review before response
5. Quality Scorecard

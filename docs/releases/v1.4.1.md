# Vibe Coding OS v1.4.1 Release Notes

**Date:** 2026-06-17
**Status:** Released
**Primary change PR:** release polish PR for v1.4.1

---

## Overview

Vibe Coding OS v1.4.1 is a patch-level stabilization release after v1.4.0. It focuses on release polish, adoption trust, CLI help correctness, and small runtime boundary cleanups. It does not expand runtime scope or introduce new features.

Highlights:

- **Docs trust polish:** stale counts and version framing updated in Vietnamese and support docs.
- **Release metadata catch-up:** CHANGELOG now includes v1.1.0 through v1.4.1 entries.
- **CLI cleanup:** help text now reflects actual `doctor --project <path>` and `events --limit=N` usage; unused/unreachable code removed.
- **Runtime boundary hardening:** misleading comments/dead code cleaned up; tmux runner validates agent commands before shell interpolation.

---

## Changes

### Docs Polish

- Fixed `README.vi.md` stale template count from 54 to 56.
- Refreshed `docs/vi/strategy-and-roadmap.md` for v1.4.0 state: 20/20 validation gates, 90 skills, 68 commands, 56 templates, optional runtime kernel, Event Store v2, and JSON observability.
- Made `docs/support-matrix.md` version-neutral instead of v1.0-framed.
- Updated `CHANGELOG.md` with v1.1.0–v1.4.1 entries and compare links.

### CLI Polish

- Updated CLI help text:
  - `doctor [--project <path>]`
  - `events [--json] [--limit=N]`
  - `install-pack <name> [--dry-run] [--force]`
- Removed unused `appendEventV2` import from `scripts/vibe-cli.mjs`.
- Removed unreachable JSON output branch in `cmdDoctor`.

### Runtime Cleanup

- Clarified task-state-machine completion behavior for tasks with subtasks.
- Removed a no-op conditional block from `runtime/tasks/task-store.mjs`.
- Updated runtime audit test fixture to use valid `in_progress` status.
- Added shell-safety guard for tmux runner agent command input and quote prompt paths before shell execution.

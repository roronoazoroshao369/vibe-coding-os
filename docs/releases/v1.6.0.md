# v1.6.0 — Adoption Trust

Release date: 2026-06-18

## Summary

v1.6.0 makes Vibe Coding OS easier to trust and easier to adopt. It closes the gap between a powerful markdown-first framework and a first-time user who needs to know exactly what to type, what files are created, and how to verify setup.

This release does **not** expand runtime scope. Runtime remains optional and scope-frozen under ADR 0002.

## Highlights

- Adoption trust foundation: roadmap/version drift guard, release metadata sync, dashboard sync, and runtime freeze guard in `validate:all`.
- README and README.vi clarify the three paths: user, maintainer/contributor, optional runtime.
- `examples/README.md` helps users choose the smallest relevant workflow example.
- Adapter docs added for Claude Code, Codex, Cursor, and Gemini.
- Vietnamese Claude Code adapter doc added for the main local workflow.
- Layer entrypoint READMEs added for `commands/`, `skills/`, `templates/`, and `registry/`.
- `vibe init --help` now documents onboarding flags and concrete examples.
- `vibe doctor --project .` now prints tool-specific next steps and runtime-optional guidance.
- Project setup tests now cover init help and doctor onboarding guidance.

## Validation

- `node scripts/test-project-setup.mjs`: **10/10 PASS**
- `node scripts/smoke-test-cli.mjs`: **70/70 PASS**
- `npm run validate:all`: expected **25/25 PASS** before merge

## Upgrade notes

No breaking core workflow changes.

If you already use v1.5.0, upgrade by pulling the latest release and re-running project-local setup only if you want the new CLI onboarding guidance:

```bash
vibe init --tool claude-code --scope recommended --current-terminal --dry-run
vibe doctor --project .
```

Runtime users do not need to migrate state for this release.

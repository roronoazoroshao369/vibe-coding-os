## Summary

v2.0.0 Quality Engine promotes the Quality Shield / Smart Adapt discipline into an orchestrated gate runner with lean/heavy profiles, structured JSON output, markdown reports, and targeted fix recommendations. It provides a repeatable, profile-driven way to execute quality gates, capture timing data, and produce actionable improvement suggestions.

This release remains additive. It does not require a daemon or hosted service, and respects ADR 0002 runtime-freeze boundaries.

## What's new

### Quality Engine runner

The core runner at `scripts/quality-engine.mjs` executes gates by profile (lean/heavy), captures timing per gate, and writes structured JSON output with fix recommendations.

### Quality Engine report generator

`scripts/quality-engine-report.mjs` produces markdown summaries and structured JSON reports suitable for release evidence, review artifacts, and scorecard sessions.

### Quality Engine skill

`skills/core/quality-engine/SKILL.md` documents how to run the engine, choose profiles, interpret output, and adopt the workflow.

### `vibe-quality-engine` command

`commands/vibe-quality-engine.md` provides a command prompt interface for running the engine with profile selection and output options.

### Quality Engine canonical guide

`docs/quality-engine-guide.md` explains all aspects: profiles, configuration, running, reporting, and adoption patterns.

## Migration guide

No migration is required. Existing workflows continue to work.

Suggested adoption path:

1. Review `docs/quality-engine-guide.md` for an overview of profiles and configuration.
2. Run `node scripts/quality-engine.mjs --profile=lean --output-json` to verify the engine works.
3. Use `vibe-quality-engine` command to integrate engine runs into workflow.
4. Generate reports with `node scripts/quality-engine-report.mjs` for release and review evidence.

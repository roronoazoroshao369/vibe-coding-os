## Summary

v2.1.0 Model-Aware Config makes Quality Engine gate selection sensitive to model capability, task risk, and project constraints before execution. It provides a declarative way to choose lean/heavy/custom gate profiles based on the AI model's known strengths and weaknesses, the task's risk level, and project-specific settings.

This release remains additive. It does not require a daemon or hosted service, and respects ADR 0002 runtime-freeze boundaries.

## What's new

### Model-Aware Config skill

`skills/core/model-aware-config/SKILL.md` documents how to configure quality gates from model capability, task risk, and project settings before Quality Engine execution.

### `vibe-model-config` command

`commands/vibe-model-config.md` provides a command prompt interface for selecting gate profiles with model awareness and project settings integration.

### Model-Aware Config canonical guide

`docs/model-aware-config-guide.md` explains all aspects: model profiles, task risk classification, gate selection, Quality Engine integration, and adoption patterns.

# Vibe Coding OS Community

## Mục đích (Purpose)

Vibe Coding OS là framework mã nguồn mở. Phần này hướng dẫn cách đóng góp, tham gia thảo luận, và trở thành maintainer.

## Cách tham gia (How to join)

1. **Đọc** [`CONTRIBUTING-SKILLS.md`](../CONTRIBUTING-SKILLS.md) — hướng dẫn viết skill.
2. **Dùng thử** trong dự án cá nhân.
3. **Báo lỗi / đề xuất tính năng** qua GitHub Issues.
4. **Đóng góp PR** cho skill, command, template mới.

## Code of conduct

- Tôn trọng — không công kích cá nhân.
- Kiên nhẫn — chấp nhận người mới có thể chậm.
- Minh bạch — mọi quyết định kiến trúc phải qua ADR.
- Cởi mở — thảo luận công khai, không DM riêng cho quyết định kiến trúc.

## Maintainer track

Maintainer là người:

- Có quyền review và merge PR.
- Cam kết duy trì ít nhất 1 area (skills, commands, templates, security, etc.).
- Phản hồi issue trong 7 ngày.
- Tham gia cuộc họp maintainer hàng tháng (nếu có).

## Communication channels

- **GitHub Issues** — bug reports, feature requests
- **GitHub Discussions** — câu hỏi chung, ý tưởng
- **PR comments** — review code

## Release cadence

- **Major version** (v3.0.0): mỗi 6-12 tháng
- **Minor version** (v2.15.0): mỗi 1-2 tháng
- **Patch version** (v2.15.1): bất cứ khi nào có critical fix

## Recognition

- Tất cả contributors được liệt kê trong CHANGELOG.md.
- Maintainer được thêm vào CODEOWNERS.

## Báo lỗi

- Bug: GitHub Issue với label `bug`
- Security: xem [SECURITY.md](../SECURITY.md)
- Docs: GitHub Issue với label `documentation`

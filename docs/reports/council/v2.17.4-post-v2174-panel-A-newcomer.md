## 4. Key Pain Points (Ranked by Severity)

### 🔴 P1: Contradictory "Quick Start" — Two approaches, no tiebreaker
CLAUDE.md says `cp CLAUDE.md commands/ skills/ templates/ /your-project/` (copy files to project). README/docs/FIRST-WORKFLOW.md says `cd ~/vibe-coding-os && npm link` (use the framework as a CLI tool). A newcomer doesn't know which path to take. The CLAUDE.md approach silently fails if you run it literally since `/your-project/` doesn't exist.

### 🔴 P2: Stat chaos — 3 different command counts in README
README L16: "113 commands." README L270: "116 commands." Disk: 115. FAQ: 116. Manifest count: 113 (array actually has 113 entries, but 2 on-disk commands are omitted: `vibe-parallel-explore` and `vibe-specify`). A newcomer navigating by "how many commands are there" gets whiplash.

### 🔴 P3: Fake validation gate numbers everywhere
- README "Validation" section: "26 gates" → actually 11
- FAQ: "33 gates" → actually 11
- FIRST-WORKFLOW.md: "26 gates" → actually 11

Only the README header (L16) correctly says "11/11 gates." This mismatch undermines trust in the documentation.

### 🟠 P4: Duplicated Wave A/B/C sections in README (40 lines)
README lines 39–58 are identically duplicated at lines 60–79. A newcomer trying to understand what v2.17.0 includes sees the same content twice. Looks unprofessional and suggests auto-merge error.

### 🟠 P5: `vibe init` name collision — CLI subcommand vs AI prompt
`commands/vibe-init.md` is an AI agent instruction (read by AI at session start). But FIRST-WORKFLOW.md Step 4 shows `vibe init claude-code` as a CLI invocation of the `vibe` tool. Two different things share the name "init." A newcomer running `vibe init claude-code` gets the CLI tool's init mode, not the AI prompt in `commands/vibe-init.md`.

### 🟡 P6: Deprecated command still on disk
`commands/vibe-specify.md` was supposed to be deprecated/unified into `vibe-spec` in v2.17.0 (per README line 34). It's still on disk with a deprecation header. Also not in manifest.json. `vibe-parallel-explore` similarly not in manifest.

## 5. Recommendations (Top 3 for Next Release)

### 1. Fix the Quick Start singularity (Critical)
Pick ONE onboarding path and make it authoritative:
- **Remove** the `cp CLAUDE.md commands/ skills/ templates/ /your-project/` from CLAUDE.md (it's error-prone)
- **Unify** all "Quick Start" references to point at FIRST-WORKFLOW.md as the sole entry point
- **Add** a decision tree: "Using Claude Code plugin? → skip to Step 3. Cloning the repo? → start at Step 1."

### 2. Audit and lock all stats (High)
- Change README L270 to "115 commands" (matches disk)
- Change README L16 to "115 commands" (matches disk)
- Remove L354's "(26 gates)" — replace with "(11 gates)" or simply remove the count
- Fix FAQ "33 gates" → "11 gates"
- Fix FIRST-WORKFLOW.md "26 gates" → "11 gates"
- Add `vibe-parallel-explore` to manifest.json OR delete it; add `vibe-specify` to manifest.json OR delete it
- **Add a CI gate** that validates README stat claims against actual disk counts (similar to `validate:no-deprecated-commands`)

### 3. Delete duplicated README content & clean up orphans (Medium)
- Remove the duplicated Wave A/B/C block (L60–79) — the first occurrence (L39–58) is sufficient
- Delete `commands/vibe-specify.md` (it was deprecated in v2.17.0, confirmed by CHANGELOG and README L34)
- Decide on `vibe-parallel-explore.md`: either add to manifest or relocate to a "legacy" directory

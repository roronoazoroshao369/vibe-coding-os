## Critical Gaps (Ranked)

### Gap 1: tool-contract.mjs Blocks 9/15 Tools (🔴 Critical)
**Mô tả:** `runtime/core/tool-contract.mjs:8-15` `defaultContracts.mcp` only allows 6 core tools. Any MCP client calling `vibe.spec`, `vibe.plan`, `autopilot.start`, etc. gets an error response despite the tools being registered.

**Fix:** Add all 15 tool names to the `mcp` adapter entry:
```javascript
mcp: [
  'task.list', 'task.next', 'task.update',
  'memory.search', 'memory.ingest',
  'checkpoint.create',
  'vibe.spec', 'vibe.plan', 'vibe.review', 'vibe.memory', 'vibe.merge',
  'autopilot.start', 'autopilot.status', 'autopilot.list', 'autopilot.stop',
]
```
**Effort:** 2 minutes. **Impact:** Unblocks all 9 non-functional tools.

---

### Gap 2: `.vibe/` Not in .gitignore (🔴 Critical)
**Mô tả:** `runtime/mcp/autopilot-tools.mjs:21` writes to `.vibe/runtime/autopilot/` but `.gitignore` only covers `.omc/`. Sessions contain rule definitions and call stats — privacy/security exposure. `.vibe/` is also in `package.json` `files` array (npm publish includes sessions).

**Fix:** Add `.vibe/` to `.gitignore`. Remove from `package.json` files array (use npm's `files` field to only ship the intended runtime code). Add TTL/garbage-collection for stale sessions (no-expiry bug).

**Effort:** 5 minutes. **Impact:** Fixes git privacy leak + npm info disclosure.

---

### Gap 3: `--help`/`--tools` Omits Autopilot (🟡 Important)
**Mô tả:** `scripts/runtime-mcp.mjs:26-28` `printHelp()` and `--tools` only call `buildTools()` and `buildCommandTools()`, omitting `buildAutopilotTools()`. CLI reports 11 tools when the server actually exposes 15.

**Fix:** Add `...buildAutopilotTools(root)` to the tools array in `printHelp()` and the `--tools` handler.

**Effort:** 2 minutes. **Impact:** Corrects CLI introspection to match actual server surface.

---

### Gap 4: README/FAQ/Plugin Stats Mismatch (🔴 Critical)
**Mô tả:** 5+ files contain conflicting skill/command/template counts. `README.md:270` says 128/96/93 (wrong). `FAQ.md:15` says 148/115/119 (wrong). `.claude-plugin/plugin.json:4` says 128/97/94 (wrong). `plugins/manifest.json:5` says v2.12.0/136/96/84 (wrong).

**Fix:** Single-source-of-truth: `validate-repo` output (115/116/107). Write a `scripts/generate-stats.mjs` that reads filesystem and generates these counts. Or: manual sweep of all 5 files in one patch.

**Effort:** 15-20 minutes. **Impact:** Eliminates the first "trust loss" moment for every new reader.

---

### Gap 5: 6/10 Workflow Commands Missing from CLI (🟡 Important)
**Mô tả:** README promises `spec → plan → implement → verify → review → memory → merge`. The CLI only supports `spec`, `plan`, `memory` as subcommands. Typing `vibe verify` or `vibe implement` returns "unknown command" — breaking the advertised workflow loop.

**Fix:** Add `case` entries to `scripts/vibe-cli.mjs` for `verify`, `review`, `merge`, `tasks`, `implement` that print the same prompt the `.md` files contain. Or: remove these commands from the README workflow table and clearly state they're AI-assistant prompts, not CLI tools.

**Effort:** 30 minutes (add cases) or 10 minutes (README reword). **Impact:** Fixes newcomer workflow expectation gap.

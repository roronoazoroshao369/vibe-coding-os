## 3. Findings (ranked by severity)

### 🔴 CRITICAL — C1: Claude Code adapter has no settings.json or conventions file

**Reproduction:**
```bash
$ ls adapters/claude-code/
README.md
# ⚠️ Only README. No .claude/settings.json. No CLAUDE.md. No CONVENTIONS.md.
$ find adapters/claude-code/ -type f
adapters/claude-code/README.md
```

**Impact:** Claude Code is the priority target per repo positioning. Users following the README install steps don't get any Claude Code-specific configuration. They have to copy `.claude/settings.json` from the root (which exists) but no adapter-specific instructions. The adapter README should ship its own example settings + conventions.

**Fix (v2.15.0):**
- Create `adapters/claude-code/.claude/settings.json` (example, with redactor wired)
- Create `adapters/claude-code/CLAUDE.md` (conventions)
- Create `adapters/claude-code/install.sh` (one-liner install)
- Modify `adapters/claude-code/README.md` (link to new files)

## 5. Risks & dependencies

- **Risk 1:** Adapter settings files (D2) for codex/gemini might use syntax those tools don't actually support. Mitigation: test install on each adapter before commit.
- **Risk 2:** Vietnamese translations (D4) need a native speaker to verify quality. Mitigation: use Claude for translation, mark as "machine-translated, needs review".

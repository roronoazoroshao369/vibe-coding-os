## 10. Risks

| Risk | Severity | Mitigation |
|------|----------|------------|
| Hook refactor (A1) breaks existing Claude Code users | High | Keep entrypoint names stable, change internals only |
| Bulk frontmatter fix (B2) corrupts SKILL.md | High | Dry-run mode first, diff review |
| Bulk `last_reviewed` update (B6) is technically false | Medium | Add comment "// bulk-updated 2026-06-20 by v2.15.0 audit" |
| Adapter settings (C2) use unsupported syntax | Medium | Test install on each adapter before commit |
| Vietnamese translations (C4) need native review | Medium | Use Claude for translation, mark "machine-translated, needs review" |
| 60 example files (C3) risk low quality | Medium | Use templates, prioritize 5 high-traffic skills first |
| Rate-limit on bypass (A4) breaks CI | Low | Env var override `VIBE_BYPASS_RATE_LIMIT=unbounded` for CI |

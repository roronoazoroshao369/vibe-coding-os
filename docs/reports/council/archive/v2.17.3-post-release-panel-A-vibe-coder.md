## Recommendations

### R1 — Sweep `vibe-specify` → `vibe-spec` across all command .md files (Priority: High, ~15 min)
The 7 command files listed in Pain Point 1 are sending newcomers to a deprecated file. Run:
```
sed -i 's|`commands/vibe-specify\.md`|`commands/vibe-spec.md`|g' \
  commands/vibe-flow.md commands/vibe-plan.md commands/vibe-align.md \
  commands/vibe-tasks.md commands/vibe-brief.md commands/vibe-checklist.md \
  commands/vibe-analyze.md
```
Verify with `grep -rn "vibe-specify" commands/`. Only `commands/vibe-specify.md` itself should match (the deprecation shim).

### R2 — Regenerate `commands/manifest.json`, `registry/prompts.json`, and `.claude-plugin/plugin.json` (Priority: High, ~10 min)
Bump version to `2.17.3`, remove `vibe-parallel-explore` and `vibe-specify` from the active command arrays (keep `vibe-specify` in `prompts.json` with its "deprecated" tag for traceability, not as an active entry), and reconcile `commands/manifest.json:count` (115 → 116 to include `README.md`, or remove README and keep 115 with explanatory note). The previous council's R4 was partially done; finish it.

### R3 — Trim `new_in_v2_11_0` from `templates/manifest.json` (Priority: Low, ~2 min)
Either remove the section (it served its purpose) or replace it with `new_in_v2_17_0`. Drop the three stale entries: `doubt-log`, `observability-plan-template`, `deprecation-notice-template`.

### R4 — Add v2.17.3 entry to `ROADMAP.md` (Priority: Low, ~1 min)
Insert after line 46:
```
- **v2.17.3** (2026-06-22) — Newcomer UX fix: CLAUDE.md orphan/deprecated references replaced (vibe-parallel-explore → vibe-flow; vibe-specify → vibe-spec); templates/manifest.json regenerated to 107; ROADMAP release history updated.
```

### R5 — Add a CI guard against regressions (Priority: Medium, ~30 min)
Add an `npm run validate:no-deprecated-commands` script that fails CI if any `commands/*.md` (other than `vibe-specify.md` itself), `CLAUDE.md`, `AGENTS.md`, or `README.md` contains the string `vibe-specify` or `vibe-parallel-explore` as a command reference. This is the structural fix that prevents this whole class of issue from recurring — the v2.17.0 → v2.17.3 patch only fixed `CLAUDE.md`, leaving the surface unguarded.

### R6 — Update `docs/QUICKSTART.md` and `FIRST-WORKFLOW.md` to reference `vibe-spec` (Priority: Low, ~5 min)
I didn't audit these files in detail this round, but they are read by every newcomer within the first 5 minutes. Worth a follow-up sweep.

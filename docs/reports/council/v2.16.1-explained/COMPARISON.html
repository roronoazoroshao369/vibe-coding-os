3 Triết lý & design approach

Sự khác biệt quan trọng nhất không phải ở số lượng, mà ở triết lý.

🚀 Vibe Coding OS — Càng nhiều càng tốt

Approach: Breadth-first. Có spec-driven workflow cho mọi thứ: spec cho bugfix, spec cho refactor, spec cho feature, spec cho documentation. 148 skills = bất kỳ task nào cũng có skill riêng, mỗi skill đều như nhau (frontmatter → overview → process → failure modes). Càng nhiều skill càng ít hỏi AI phải tự suy luận.

🔬 ClaudeKit (duthaho) — Đúng thứ cần, làm thật sâu

Approach: Depth-first. 15 skills, mỗi skill là 1 file dài 30-50 dòng mẫu (rationalization tables, evidence requirements, red flags). Skill design: "If you can skip it, it wasn't worth writing." Từ chối bị skip silently. Chỉ viết skill nếu task thực sự lặp lại hàng ngày.

📦 mrgoonie/claudekit-skills — Nhiều hơn là tốt

Approach: Cộng đồng đóng góp. 200+ skills từ community. Chất lượng không đồng đều — có skill rất hay, có skill copy-paste từ ClaudeKit khác. Không có quality gate, không có validation. "Quantity over quality."

🛠 carlrannaberg/claudekit — Tool-first

Approach: CLI-utility-first. Hooks (pre-commit, post-commit), commands (gh, git), agents (10+ role definitions). Ít workflow enforcement, nhiều "giúp tôi làm việc này nhanh hơn". Không phải OS, là toolbox.

Thực tế: duthaho/claudekit làm đúng điều vibe-coding-os thiếu

Feature độc quyền của duthaho/claudekit
  • Rationalization Tables — mỗi skill có 1 bảng "excuse vs rebuttal". Ví dụ trong skill verification-gate: "I see the problem, let me just patch it" → "If you're patching without verification, you haven't found the root cause — you're guessing." Vibe Coding OS không có pattern này.
  • 5 Output Styles — Brainstorm, Deep Research, Review, Implementation, Token Efficient. Mỗi style điều chỉnh hoàn toàn cách AI giao tiếp. Vibe Coding OS có 120 commands thay vì 5 style.
  • Pre-completion gate — "Chưa verify trước khi nói done = không bao giờ verified". Mạnh hơn verify command của vibe-coding OS vì nó là gate bắt buộc, không phải optional step.
  • 8 agents rõ ràng — mỗi agent 1 job, 1 dispatcher file. Không phải orchestrate general-purpose agent. Vibe Coding OS có team orchestration nhưng thiếu agent profiles chuyên biệt.

Thực tế: vibe-coding OS làm đúng điều ClaudeKit thiếu

Feature độc quyền của Vibe Coding OS
  • Spec-driven OS — spec đầu tiên, mọi thứ xoay quanh spec. ClaudeKit không có khái niệm "spec" mandatory — skills nhảy thẳng vào action.
  • 120 commands — bao phủ từ spec, plan, tasks, implement, verify đến merge. ClaudeKit: 15-40 commands.
  • 3-layer security — injection defense 97.37% coverage + redactor 60/60 tests + approval gate. ClaudeKit: 0 security layer.
  • 38 validation gates — structure, injection, quality, secret scan, drift detection. Chạy CI, tự động. ClaudeKit: 0 gates.
  • 9 editor adapters — Claude Code + Codex + Cursor + Gemini + Cline + Continue + Aider + Windsurf + MCP. ClaudeKit: Claude Code only.
  • Bilingual — EN + VI. ClaudeKit: EN only.
  • Memory architecture — 20 skills về memory. ClaudeKit: 0.

5 Điểm mạnh — Vibe Coding OS so với ClaudeKit

✅ Vibe Coding OS vượt trội ở

Bề dày tính năng

120 commands + 148 skills + 110 templates + 38 validation gates. ClaudeKit lớn nhất có ~200 skills/40 commands, không có gates, templates hay runtime.

Bảo mật

3-layer injection defense + redactor 60/60 tests + approval gate. ClaudeKit có 0 layer security nào. Đây là khác biệt lớn nhất.

Độc lập editor

9 adapters = không bị lock-in với 1 AI tool. ClaudeKit: Claude Code là chính, còn lại không có.

Validation tự động

38 gate chạy CI, tự động audit structure, injection, secret, quality, drift. ClaudeKit: không có gate tự động nào.

Runtime & MCP

25 .mjs + 11 MCP tools + event store + approval gate. ClaudeKit: không có runtime, không có event store.

Memory architecture

20 skills về memory, 4-layer (project/session/harness/runtime), vector store local, search/retrieve/ingest/cite. ClaudeKit: 0.

Bilingual + community

EN + VI song ngữ. ClaudeKit: EN only.

Open source license

MIT/Apache 2.0. mrgoonie/claudekit-skills: NO LICENSE — không thể fork thương mại.

6 Điểm yếu — Vibe Coding OS so với ClaudeKit

⚠️ ClaudeKit vượt trội ở

🪞 Rationalization Tables

Mỗi skill ClaudeKit (duthaho) có 1 bảng "excuse → rebuttal". Bảo AI đừng lười. Vibe Coding OS không có — skill chỉ nói "làm X" mà không nói "đừng bào chữa X".

🎨 Output Styles

5 styles (Brainstorm / Deep Research / Implementation / Review / Token Efficient) thay đổi hoàn toàn "giọng nói" của AI. Vibe có 120 commands thay vì 5 style. Có cái hay riêng, nhưng ClaudeKit approach dễ dùng hơn.

🤖 Agent Roles rõ ràng

8 agents (planner, architect, experience-reviewer, investigator, tester, code-reviewer, security-auditor, scout) mỗi agent 1 job duy nhất. Vibe có team orchestration nhưng agent profiles chưa rõ ràng bằng.

📐 Pre-completion gate

ClaudeKit "không bao giờ nói done trước verify" — gate bắt buộc AI phải chạy test trước khi assert done. Vibe có vibe-verify command nhưng là step optional, không phải gate bắt buộc.

🎯 Scope control tốt hơn

ClaudeKit có "When to use / When NOT to use" trong mỗi skill. Vibe có nhưng không mạnh bằng — ClaudeKit nói rõ "đừng dùng skill này nếu..."

📝 Văn phong README

duthaho/claudekit có README chuẩn mực: "No founder voice. No 'ambitious vision,' no '10x outcomes,' no 'delight.'" Vibe Coding OS README thiếu conservative engineering voice này.

⭐ Community trust

mrgoonie/claudekit-skills có 2,157⭐ — gấp đôi bất kỳ ClaudeKit nào. Community size = trust signal. Vibe Coding OS cần build community.

🪶 Lightweight

duthaho/claudekit có 15 skills, 8 agents, 108 files. Vibe Coding OS có 1,242+ files. Không phải lúc nào nhiều hơn cũng tốt hơn.

Cụ thể: Rationalization Table pattern

Đây là thứ vibe-coding-os nên import ngay. Pattern:

## Rationalizations

| Cái cớ phổ biến | Phân tích steelman | Failure mode nếu làm theo | Hành động thay thế |
|----------------|-------------------|--------------------------|-------------------|
| "Tôi thấy vấn đề rồi, để tôi fix luôn" | Đúng, bạn có thể thấy vấn đề, nhưng nếu chưa investigate root cause, fix chỉ là guess | Patch không đúng root cause → bug tái phát, hoặc tạo bug mới | Chạy `investigate-root-cause` trước, rồi mới implement |
| "Tôi đã chạy test rồi, PASS hết" | AI thường "tin" nó PASS mà không chạy thực tế | AI nói dối không chủ ý — hallucination | Chạy `verification-gate` — phải paste stdout thực tế |
| "Tôi biết convention rồi" | AI có thể biết nhưng dễ ignore vì "em thấy style khác đẹp hơn" | Code không đồng nhất → review reject | Chạy `validate-convention` trước khi commit |

Giải thích Feynman: Hồi nhỏ đi học, thầy giáo nói "Làm bài tập về nhà". Học sinh lười: "Em biết làm rồi, không cần làm." Thầy: "Biết mà không làm = không biết." Rationalization Table = trích dẫn sẵn câu nói của học sinh lười + lý do tại sao nó sai + hậu quả + cách làm đúng. AI cũng như học sinh — cần bị "bắt bài" trước khi nó kịp bào chữa.

8 Kết luận

8.1 Vibe Coding OS mạnh hơn ở

  • Bề rộng: 148 skills, 120 commands, 110 templates — không có ClaudeKit nào sánh bằng
  • Bảo mật: 3-layer injection defense + redactor — ClaudeKit không có tí gì
  • Runtime: 25 .mjs + MCP server + event store — ClaudeKit không có runtime
  • Validation tự động: 38 gates — ClaudeKit 0 gates
  • Portability: 9 editor adapters — ClaudeKit chỉ Claude Code
  • Memory layer: 20 skills — ClaudeKit 0

8.2 ClaudeKit mạnh hơn ở

  • Rationalization Tables — pattern thiết kế skill hay nhất ecosystem hiện nay
  • Depth: duthaho/claudekit 15 skills nhưng mỗi skill dài hơn, có "mental friction" để chống skip
  • Output Styles: 5 style thay đổi voice AI — cách tiếp cận nhẹ hơn 120 commands
  • Agent roles rõ ràng: 8 agent, 1 agent = 1 job
  • Văn phong engineering: "No founder voice" — tạo trust với senior engineers
  • Community: 2,157⭐ cho claudekit-skills

8.3 Tóm tắt 1 câu

Vibe Coding OS = Windows (hệ điều hành đầy đủ: runtime, security, validation, memory, 9 editors, 148 skills, 38 gates) 😊 ClaudeKit = macOS (gọn nhẹ, thiết kế tinh tế, rationalization tables, output styles, agent roles, "just works").

Không cái nào "tốt hơn" tuyệt đối. Cả hai đều solution cho cùng problem (AI code thiếu kỷ luật), nhưng approach khác nhau. Vibe nhiều tính năng hơn = phù hợp với AI agent platform. ClaudeKit ít hơn nhưng sâu hơn = phù hợp với dev có chọn lọc.

Điều tuyệt vời: cả hai đều MIT (Apache), có thể kết hợp được. Import rationalization tables từ ClaudeKit vào Vibe = "Windows với thiết kế macOS".

🔴 Critical Gaps

1. No Linter — 0% Code Lint Coverage

Zero ESLint, zero TypeScript, zero Prettier in the entire repo. Mid-tier models ship unused variables, broken async patterns, and unreachable code every session. A 10-minute ESLint install covers 50+ bug patterns — more than the 6 theater gates combined.

2. validate-typecheck.mjs Always Exits 0

Line 141: process.exit(0) — advisory only. This script already checks 8 common misspelling patterns (e.g., readdFile→readFile) but never fails the pipeline. A 5-minute one-line change: process.exit(warnings.length > 0 ? 1 : 0).

3. No Mid-Tier Model Entry Point

CLAUDE.md lists 115 skills, 113 commands — overwhelming for a 32k-context model. No hint to "load one skill at a time" or "skip orchestration commands." A 30-minute CLAUDE-LITE.md would unlock mid-tier usage.

4. Self-Auditing Paradox

Self-review skills (verification-before-done, quality-execution-contract) ask the model to verify its own output. Mid-tier models cannot detect their own errors — they pass their own audit with false confidence. The only escape is external validation (ESLint, typecheck, tests).

5. No Runtime Feedback Loop

The autopilot logs errors to .vibe/runtime/autopilot/ but no gate reads those logs. If a skill causes repeated ToolExecutionError crashes, each new user hits the same crash independently. No aggregated feedback reaches the validation pipeline.

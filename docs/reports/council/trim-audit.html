Loop Architecture

1. SPEC INTAKE → read .omc/specs/X.md
       ↓
2. CODE → apply smallest safe diff
       → approval-gate: auto-approve safe, deny destructive
       ↓
3. TEST → npm run validate + targeted suite
       → if red: jump to step 4
       ↓
4. FIX → re-read failure, generate hypothesis, patch
       → retry from step 3 (cap 3x)
       ↓
5. COMMIT → git add + commit (local)
       ↓
6. REVIEW → spawn 3 independent contexts
       → majority-wins, escalate iff blocker majority
       ↓
7. MERGE → tier ≤ small: local merge
       → tier = medium: open PR + wait CI
       → tier = risky: human approval

🔴 3 Critical Gaps

🔥 Gap 1 — Tool Contract Blocks 9/15 MCP Tools Critical · 2 min fix

Where: runtime/core/tool-contract.mjs:8-15

What happens: Any MCP client calling vibe.spec, autopilot.start, etc. gets: "Tool not allowed for adapter mcp" — despite tools being registered and advertised.

Why: defaultContracts.mcp only lists 6 core tools. The 5 vibe.* + 4 autopilot.* tools were added to the server after the allowlist was written.

Fix: Add all 9 missing tool names to the mcp array:

'vibe.spec', 'vibe.plan', 'vibe.review', 'vibe.memory', 'vibe.merge',
'autopilot.start', 'autopilot.status', 'autopilot.list', 'autopilot.stop'

🔥 Gap 2 — `.vibe/` Runtime State Leaks into Git Critical · 5 min fix

Where: .gitignore (missing .vibe/), package.json files array (includes .vibe/)

What happens: Autopilot sessions (.vibe/runtime/autopilot/*.json), audit logs (audit.log), and .vibe/setup.json are tracked by git and included in npm publish. Sessions contain rule definitions, agent labels, and call statistics.

Fix:

.gitignore: add ".vibe/"
package.json: remove ".vibe/" from files array
